**Detalle de minuta**

**Introducción**

La librería “Laelsi” es un negocio dedicado a la venta de productos de librería, juguetería, imprenta digital (incluye impresiones, fotocopias y diseño gráfico) y sellos. Artículos de computación y cotillón se quieren incluir a futuro.  
 El dueño nos encargó desarrollar un sitio web para las ventas y un conjunto de paneles para la administración del negocio. Los paneles y el sitio están comunicados.  
 Además, se quiere incluir al comercio web un chatbot y un ícono de WhatsApp e Instagram. Se pide la construcción de un panel estadístico de las compras.

**Descripción del negocio**

El negocio abre de lunes a sábados. El horario es normalmente de 8:00 a 17:00 horas de lunes a viernes; y sábados de 9:00 a 13:00 horas. Este horario puede cambiar dependiendo de la decisión del único dueño. En el negocio trabaja el dueño y una empleada. El negocio cuenta con impresoras, dos computadoras y máquinas para la preparación de trabajos post-impresión.

Los clientes no necesitan dejar sus datos para hacer una compra, pero pueden acceder al número del negocio para hacer pedidos desde el celular por Whatsapp. Así, los clientes son organizados desde el Whatsapp Business del negocio. Hay un celular específico para el negocio y su Whatsapp Business se usa desde la PC principal.

La PC principal se utiliza para responder la bandeja de mensajes de e-mail, Whatsapp, Facebook e Instagram (de todos estos medios se reciben pedidos), pero si son ventas no se ofrece envío. Se llevan a cabo compras online a proveedores como TioTom, Paraná, etc. y por Mercado Libre. La PC principal posee carpetas de impresiones y diseño, en donde se descargaron los archivos necesarios para imprimir, editar o diseñar.  
 Para las formas de pago y cobro se usan las transferencias a billeteras virtuales, efectivo, QR, depósito bancario, transferencias bancarias o con tarjeta de crédito y débito.

Hay un sistema de Posnet y QR de billeteras virtuales. Del Posnet se archivan los comprobantes de venta en un cuaderno.  
 Existe una segunda PC que se utiliza para documentar las ventas diarias en el sector de atención al público. Las ventas del día se guardan en un archivo Word y tiene la descripción de cada venta, la forma de pago y el total recaudado del día.

Cada archivo, en el que se documentan las ventas diarias, tiene la siguiente estructura:

| DIA, NÚMERO de MES de AÑO (Ej: Viernes, 5 de Abril de 2024\) |                              |              |                  |
| :----------------------------------------------------------- | :--------------------------- | :----------- | :--------------- |
| 1                                                            | prod1 \| prod2 \| … \| prodN | \$ cantidad1 | (medio de pago)  |
| 2                                                            | prod1 \| prod2 \| … \| prodN | \$ cantidad2 | (medio de pago)  |
| …                                                            | …                            | …            | …                |
| n                                                            | prod1 \| prod2 \| … \| prodN | \$ cantidadN | (medio de pago)  |
| Total ingresado en el día:                                   |                              |              | \$ cantidadTotal |
| Comentarios:                                                 |                              |              |                  |
|                                                              |                              |              |                  |

Aclaración: el documento [Stock Laelsi](https://docs.google.com/document/d/1KChTXpGXxM806auokKGnHKvkUhxZzgdpDd2jytDil8I/edit) especifica el sistema que se idea como solución.

Cuando un cliente entra al local, se encuentra ya en el área de atención al público y es atendido por la empleada.Todo lo que está a la vista está en las estanterías del negocio. Hay juguetes, artículos de librería, productos de computación, sellos, mochilas, etc.

Si el cliente requiere un producto, éste le pide a la empleada lo que necesita y la empleada busca el producto u ofrece otro en reemplazo del pedido. El cliente puede consultar sobre un producto explicando su inquietud para que el empleado encuentre el mejor producto que pueda ofrecerle.

Los pedidos de los clientes se pueden hacer mediante Whatsapp, Instagram, llamada telefónica, mail o de manera presencial en el negocio. Cuando el cliente pidió un producto y éste no está en el negocio entonces se busca dicho producto para ser comprado de distintos proveedores, se comunica el precio y, si se acepta el precio entonces se compra para que luego el cliente venga a retirarlo luego de pagar. Si no se acepta el precio no se le compra el producto al proveedor.

Si no se consigue el producto pedido de los proveedores, se informa al cliente que no tiene posibilidad de conseguir dicho producto y no se efectúa la venta.

Al hacer la compra, el cliente debe pagar. El cliente suele consultar las formas de pago y los beneficios o desventajas de dichas formas de pago. Las formas de pago son efectivo, depósito bancario, débito, crédito, billetera virtual u otra.  
 Una vez que el cliente hizo su compra ya entonces se retira del local. Si la compra fue por un medio digital entonces debe venir a retirar el producto.

El negocio cuenta con un lugar que utiliza como almacén y allí guarda los productos que, por cuestiones de espacio, no puede mostrar en el frente del negocio. Además de vender productos variados, el negocio hace impresiones, diseño gráfico, trabajos de post-impresión y fotocopias.

Los trabajos de post-impresión son abrochado, intercalado, troquelado, perforación, emblocado, corte, doblado, medio corte en papel autoadhesivo, plastificado, abrochado y anillado, encolado, laminado, numerado.  
Lo que suele pedir el cliente es encuadernado, anillado, abrochado, perforado, emblocado y plastificado, encolado, laminado, numerado.  
El encuadernado es abrochado, encolado y con o sin laminado de tapa

En el almacén y, a veces, en el frente se llevan a cabo trabajos de post-impresión.
